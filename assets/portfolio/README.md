# assets/portfolio/

Imagens do portfólio de bolos decorados (temáticos, futebol, festas) e
bandejas de docinhos.

As fotos reais ainda não foram fornecidas. Enquanto isso, os itens do
portfólio são referenciados em `content/cardapio.json` com nomes de
placeholder (ex: `portfolio-01.jpg`). Substituir pelos arquivos reais
quando disponíveis, mantendo os mesmos nomes ou atualizando as referências
no JSON.
